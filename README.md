# Amazon Atelier — Editorial Luxury E-Commerce Redesign

> What if Amazon was re-engineered from zero for high-ticket luxury, architectural objects, and sub-second performance?

## Overview
Amazon Atelier is an editorial concept remake of Amazon designed and engineered by Mobpie. It completely strips away promotional grocery banners, multi-megabyte app bloat, and discount bin chaos — replacing them with an architectural, high-fashion e-commerce experience.

## Key Highlights
- **Sub-0.3s Headless Load Speed**: Instant faceted filtering across categories, price spectrums, designer houses, materials, and Prime express fulfillment.
- **16 Curated High-Ticket Objects**: Leica M11 Monochrom, Teenage Engineering OP-1 Field & TP-7, Bang & Olufsen H95, Grand Seiko Snowflake, Knoll Wassily Chair, Byredo Parfums, and Atelier garments.
- **Multi-Currency Real-Time Engine**: Dynamic conversion between USD ($), EUR (€), GBP (£), and INR (₹).
- **Dedicated Native Mobile App UI**: Tailored bottom dock, thumb-friendly slideout drawers, and 1-tap Prime commission checkout.
- **Architectural Dark Mode Aesthetics**: Precision typography, tactile tilt physics, and industrial minimalist design.

## Tech Stack
- **Frontend**: HTML5, CSS3 (Modular CSS Variables), Pure Vanilla ES6+
- **Interactions**: Custom Faceted Filter Engine, Multi-Currency Exchange Bus, 3D Card Tilt Physics
- **Deployment**: Vercel Edge Network
